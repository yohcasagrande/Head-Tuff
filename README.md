# Headtuff

Site da Headtuff (headtuff.com). Página única em HTML, sem etapa de build.

- `index.html`: o site inteiro (estilos, produtos do Drop 001 e ilustrações dos bonés).
- Publicação: projeto `headtuff` na Vercel.
- Publicação automática: cada envio para a branch `main` atualiza o headtuff.com.
